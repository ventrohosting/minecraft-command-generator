# Minecraft Command Generator

Minecraft Command Generator für die Java Edition: /give mit Name, Lore und Verzauberungen, /tellraw mit Farben und Klick-Aktion und /summon zusammenklicken…

**Online nutzen:** [Minecraft Command Generator](https://ventrohosting.com/tools/minecraft-command-generator) · Demo: https://ventrohosting.github.io/minecraft-command-generator/

## Funktionen

- /give mit Namen, Lore, Verzauberungen und unzerstörbar
- /tellraw mit Farben, Stilen, Klick- und Hover-Aktion
- /summon mit Namen und Schaltern wie NoAI

## English

Minecraft command generator for Java Edition: build /give (name, lore, enchantments, unbreakable), /tellraw (colours, styles, click and hover events) and /summon commands. Every option checked on Paper 1.21.11 and 26.3. Runs entirely in the browser.

Use it online: https://ventrohosting.com/tools/minecraft-command-generator

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Alles läuft im Browser, es werden keine Daten gesendet.
